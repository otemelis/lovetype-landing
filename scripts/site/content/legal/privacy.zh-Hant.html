LoveType 是一款關於感情與人際關係的自我覺察 App。本政策說明哪些資料留在你的 iPhone 上、少數不留在手機上的資料，以及原因。

重點摘要

  • 不需帳號。我們從不詢問你的姓名、電子郵件或電話號碼。
  • 你的答案留在你的 iPhone 上，絕不會傳送給我們。
  • 我們會蒐集匿名的使用事件，以了解 App 的使用情形，包括你得到的結果類型。
  • 我們不販售資料、不顯示廣告，也不跨其他 App 或網站追蹤你。

留在你裝置上的資料

你在每項測驗的答案、你的結果、你的 LoveType 檔案，以及你選擇輸入的名字，都只存放在 App 於你 iPhone 上的私有空間。你可以隨時在「設定」→「重設所有測驗結果」中全部刪除，或直接刪除 App。

我們蒐集的資料

使用 LoveType 時，App 會記錄匿名的使用事件，例如：開始或完成了一項測驗、你得到的結果類型（例如「和事佬」）、看了某個畫面，或完成了一筆購買。每個事件包含：

  • 在你裝置上產生的隨機安裝 ID，以及隨機的工作階段 ID；
  • App 版本、iOS 版本與平台；
  • App 語言與裝置上設定的地區（僅到國家層級）；
  • 事件發生的時間。

事件絕不包含你的答案、姓名、電子郵件、聯絡人或精確位置。安裝 ID 不會連結到你的 Apple ID 或任何其他身分，刪除 App 後也會重設。

與伴侶對照

使用「與伴侶對照」時，App 會顯示一組四個字元的代碼。代碼只包含你的三種結果類型（依附、愛與衝突），沒有其他內容。只有你自己分享時才會被分享，而對照是在各自的手機上進行。在 love-type.app 的對照頁面輸入的代碼，會在你的瀏覽器中解讀，不會傳送給我們。

意見回饋

如果你選擇透過 App 傳送意見回饋，你寫下的文字會與你的評分和結果類型一起保存，讓我們能夠閱讀。請不要在其中填寫個人資料。

購買

LoveType 完整指南是 App 內的一次性購買。所有付款都由 Apple 處理，我們看不到你的付款資訊。我們使用 RevenueCat 來確認購買並在你的裝置間回復購買，使用的是 RevenueCat 產生的匿名 ID。

服務供應商

  • Supabase：代我們保存匿名的使用事件與選填的意見回饋。
  • RevenueCat：管理購買狀態與回復購買。
  • Apple：處理付款；若你同意與開發者分享，也會提供當機報告與匿名的 App Store 分析資料。

我們不會將資料販售或出租給任何人，也不會用於廣告。

本網站

love-type.app 是託管於 GitHub Pages 的靜態網站。它不使用 Cookie，也不會在你的裝置上儲存任何東西。為了了解哪些頁面能幫助大家找到這款 App，網站會將少量匿名事件傳送到同一個 Supabase 服務：瀏覽的頁面、來源網站、是否點了 App Store 按鈕、瀏覽器語言，以及大致的裝置類型（手機、平板或電腦）。每個事件都帶有一個只在那次頁面瀏覽期間存在的隨機 ID，因此各次造訪無法彼此連結，也無法連結到你本人，我們也不會儲存你的 IP 位址。網站沒有任何廣告或第三方追蹤程式碼。GitHub 可能會為了提供與保護網站而處理標準的伺服器紀錄，例如 IP 位址。

你的選擇與權利

你可以在 App 的「設定」中刪除裝置上儲存的所有資料。由於我們蒐集的事件是匿名的、不會連結到你，我們無法應要求找出特定某個人的事件，因為其中沒有任何能識別你的資訊。若有任何隱私相關的問題或請求，請寫信到下方地址。
