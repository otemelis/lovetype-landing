# love-type.app build

The site is static HTML generated by `scripts/site/` and committed (GitHub Pages serves the
repo root; `.nojekyll` must stay). Never edit generated `index.html` files by hand.

```
node scripts/site/sync-app-data.mjs        # copy FREE result text from ../lovetype (6 languages)
node scripts/site/build.mjs                # write every page, 404.html, sitemap, robots, llms.txt
node scripts/site/check.mjs                # links, titles, descriptions, canonicals, JSON-LD
python3 scripts/site/render-og.py <DMSerifDisplay.ttf> <sans.ttf>   # 1200×630 share images
```

## Where things live

| Path | What |
|---|---|
| `scripts/site/lib.mjs` | Page shell: head/SEO/schema, header, footer, pill, phone, heart |
| `scripts/site/model.mjs` | Data model: 16 styles, 10 LoveTypes (+ archetype points mirrored from the app's `profileSynthesis.ts`), 52 pairings |
| `scripts/site/content/types.mjs` | Web-only copy: definitions, signs, FAQs, hub text |
| `scripts/site/content/compat-*.mjs` | The 52 pairing write-ups (from the app's `compare.pairs`) |
| `scripts/site/content/journal/`, `legal/` | Article and legal bodies |
| `scripts/site/data/app-<lang>.json` | Free result text synced from the app. Premium text is never copied: this repo is public |
| `scripts/site/pages/*.mjs` | Page builders |
| `assets/site.css` | The whole design system |
| `assets/js/glare.js` | Edge light (WebGL port of the app / POIS shader, LoveType palette) |
| `assets/js/heart.js` | The raymarched 3D heart |
| `assets/js/site.js` | Menu, reveals, story stepping, pair picker, compare-code decoder |
| `assets/og/src/heart-<family>.png` | Lit hearts for share images: open `/scripts/site/og-heart.html?f=<family>` on a local server and screenshot `.heart` with a transparent background |

## Analytics

`assets/js/analytics.js` sends cookieless events to the shared Supabase `track` function as
`app_id = 'lovetype-web'` (own API key, separate from the app's; its hash is in `app_api_keys`).
Nothing is stored on the device; each page view has its own random id. localhost traffic is
`environment = 'dev'`. Events: `page_view`, `app_store_tap`, `compare_code_decoded`,
`pair_picked`, `starter_line_copied`, `language_switched`. A new event name needs an
`event_catalog` row first or it is rejected. Ready-made queries: `scripts/site/analytics.sql`.

## Languages

Home, compare, privacy and terms exist in en, es, pt-BR, ja, zh-Hant and id
(`/es/`, `/pt-br/`, `/ja/`, `/zh-hant/`, `/id/`). Strings: `scripts/site/content/i18n/<lang>.mjs`;
legal bodies: `content/legal/<page>.<lang>.html`; screens: `assets/screens/<lang>/`. All other
pages are English and are linked with `hreflang="en"`. Translations are drafts pending native review.

## Rules

- URLs end with a slash; canonicals and the sitemap use the slash form.
- The compare decoder in `site.js` and the archetype points in `model.mjs` must match the app
  (`src/logic/compareCode.ts`, `src/logic/profileSynthesis.ts`). Never reorder the enum arrays.
- `/compare/<code>` without the app falls through to `404.html`, which shows the decoded LoveType.
  `.well-known/apple-app-site-association` opens those links in the app once a build ships
  with Associated Domains.
- No prices anywhere; the App Store sets them per country.
